# Roadmap

- [x] **Standalone Linux CLI.** Read the sequence from a file or stdin and export SVG or PlantUML using the website’s Elm parser, diagram layout, and themes. See the [CLI usage and build instructions](cli/README.md).
- [x] **VS Code extension.** Edit `.seq` files with syntax highlighting, indentation, line-level parser errors, and an offline live preview. See the [installation and build instructions](vscode/README.md).
- [x] **Collapsible calls in the diagram.** Start a walkthrough with **Collapse all**, then open one activation at a time to explain the main flow before revealing its details. Fixed positions keep the diagram steady. Compact layout is available for larger diagrams. The preview and full-screen viewer share their fold state.
- [x] **JSON Schema viewer.** Explore JSON Schema and OpenAPI JSON with collapsible nodes, themes, and SVG export in the browser, CLI, and VS Code. See the [JSON Schema viewer documentation](schema/README.md).
